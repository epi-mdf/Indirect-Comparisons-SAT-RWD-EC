# Indirect-Comparisons-SAT-RWD-EC
Systematic review of indirect comparisons of single-arm trials supplemented with real-world external controls.


## 1. Data
In `~/000data/`.  
All the data files used to make the analyses.  
See `~/000data/000README_DATA.md` for precisions on file names and function.  


## 2. Codes
In `~/000codes/`, we used a R project for the codes, beware of file paths.  
See `~/000codes/0000session_information.txt` for session information.  
Code files are labelled explicitely and have an explicit header.  


## 3. Results
In `~/000results/`.  
Output of codes (Word tables and figures for publication).
